# B02 Market Data Infrastructure
Implemented a provider interface and in-process single-flight cache for 32 instruments, 15m and 1h. Cache TTL 60 seconds from scan start. Two timeframe fetches, each four concurrent symbols. Concurrent calls share the same promise; failed refresh is not cached.
Quality gates: reject nonfinite and inconsistent OHLC, future/unclosed bars; sort and deduplicate timestamps. Require 220 15m and 820 hourly bars and 80% FX history coverage. Engine rejects incomplete 4h buckets and opening range gaps, excludes stale pairs from currency strength and directional focus/watch, rejects zero ATR. Empty results throw so the credit wrapper refunds. Existing live field now represents last closed price, not a real-time quote; warnings explicitly label this.
Current coverage measures historical availability, not current market freshness. Stale threshold remains legacy 3 hours; weekend/holiday calendar and fresh-pair coverage policy are outstanding. Existing ranking thresholds and Dhaka session schedule are unchanged. Historical data provider licensing and market data quality must be verified before commercial release.
Next: real Postgres migration and concurrency tests, persistent shared snapshots and distributed locking, provider fallback, per-asset market calendars, 1m/3m support, explicit source/as-of metadata and versioned API. Tests committed but not executed. No frontend edits.
