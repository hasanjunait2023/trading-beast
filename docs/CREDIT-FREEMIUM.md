# TradingBeast credit-based freemium
Approved: 10 non-expiring credits per UTC calendar day, starting signup or rollout (2026-11-28), whichever is later; each explicit radar trigger costs 10, same wallet for Telegram, Mini App and browser. Lazy grants catch up for offline days. Failed analysis exceptions refund. No recurring automatic paid scan.
Proposed, not yet activated: Free 10/day; Pro additional 300 credits per verified monthly renewal; Elite additional 900 credits per verified monthly renewal. All retain base daily grants. Paid tiers differentiate advanced alerts, correlation, journal, strategy and AI; feature releases are gated until implemented. Optional top-ups later. Prices require data cost and conversion validation. Telegram digital purchases must use Stars; no in-bot external payment offers.
Before deploy: run Prisma generate and create/apply reviewed migrations (development only: prisma db push); verify existing user data; configure strong JWT secret, ADMIN_TELEGRAM_IDS, TELEGRAM_WEBHOOK_SECRET, TELEGRAM_MINI_APP_URL (HTTPS). Rotate old JWT secret; re-register webhook with secret token. Configure BotFather menu button and main Mini App. /app inline button and /login private one-time code are implemented. Run backend build/tests and frontend builds; exercise concurrent debit, duplicate trigger, refund, offline accrual, login, callback and expiry against test database. Existing automatic trials are no longer issued, existing subscriptions retain expiry. Do not deploy until integration checks pass.
Known limitations: no paid credit grants/top-ups yet, no durable pending-job recovery after server crash, no persistent result history or cross-channel idempotent result replay, no centralized market data snapshot worker yet, no wallet concurrency integration tests executed. UTC grant boundary and rollout epoch are product defaults; validate before deployment.
